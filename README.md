# 🌸 Iris Flower Classification using Machine Learning

## 📌 Project Overview

This project implements an Iris Flower Classification system using Machine Learning. The model classifies Iris flowers into three species: Setosa, Versicolor, and Virginica based on their sepal and petal measurements.

## 🎯 Objective

The main objective of this project is to understand and implement a basic classification problem using Machine Learning and Scikit-learn.

## 📊 Dataset

The Iris dataset contains 150 flower samples with four input features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The target classes are:

* Setosa
* Versicolor
* Virginica

## 🛠️ Technologies Used

* Python

* Scikit-learn

## 🤖 Machine Learning Model

A **Decision Tree Classifier** is used to train the model and classify the Iris flower species.
